# 08 部署与运行

## 1. 本地开发环境搭建

### 1.1 前置依赖

| 软件 | 版本 | 用途 |
| --- | --- | --- |
| JDK | 8 | 后端编译运行 |
| Maven | 3.6+ | 后端构建 |
| Node.js | 16.x（建议） | 前端构建 |
| MySQL | 8.0 | 数据库 |
| Redis | 7 | 验证码/支付映射缓存 |

### 1.2 初始化数据库

```bash
mysql -uroot -p < cloudland.sql    # 建库 cloudland + 建表 + 测试数据
```

### 1.3 启动后端（端口 9090）

```bash
mvn spring-boot:run          # 主类 com.cloudland.CloudlandApplication
# 或
mvn clean package -DskipTests
java -jar target/Cloudland-0.0.1-SNAPSHOT.jar
```

默认连接 `localhost:3306` 的 MySQL（root/123456）与 `localhost:6379` 的 Redis（密码 123456），可用环境变量覆盖（见 §3）。

**本地私密配置**：创建 `config/application-local.yml`（已 gitignore，经 `spring.config.import` 加载），覆盖邮件密码、支付宝密钥等敏感项。**该文件含真实凭据时严禁提交。**

### 1.4 启动前端（端口 8080）

```bash
cd vue
npm install
npm run serve              # http://localhost:8080
```

可选 `vue/.env.local`：

```bash
VUE_APP_API_BASE_URL=http://localhost:9090     # 后端地址
VUE_APP_FRONTEND_BASE_URL=http://localhost:8080
```

> 开发模式下前端直连 `http://localhost:9090/api`（axios baseURL），依赖后端 CORS 放行（默认已含 `http://localhost:8080`）。

### 1.5 验证

- 打开 `http://localhost:8080` 应看到云用地首页
- 土地/产品列表能加载（免认证接口）即后端连通
- 登录任一测试账号（见 `cloudland.sql` user 表，如 phone `18140213284`）

## 2. Docker 部署（推荐）

### 2.1 一键启动

```bash
cp .env.example .env        # 按需修改密钥/密码
docker-compose up -d
```

四个服务：

| 服务 | 容器名 | 端口 | 说明 |
| --- | --- | --- | --- |
| frontend | cloudland-frontend | **80:80** | nginx-alpine 静态资源 + `/api/` 反代 |
| backend | cloudland-backend | 9090（未映射宿主） | openjdk8-slim 运行 jar |
| mysql | cloudland-mysql | 3306:3306 | 首次启动自动导入 `cloudland.sql` |
| redis | cloudland-redis | 6379（未映射宿主） | `--requirepass` 启动 |

镜像统一从 `docker.1panel.live` 镜像源拉取（国内加速）。

### 2.2 后端 Dockerfile（多阶段构建）

```
阶段1: maven:3.8.6-openjdk-8
  配置阿里云 Maven 镜像 → mvn dependency:go-offline（依赖层缓存）
  → COPY src → mvn clean package -DskipTests
阶段2: openjdk:8-jre-slim
  COPY target/*.jar app.jar → EXPOSE 9090 → java -jar app.jar
```

### 2.3 前端 Dockerfile（多阶段构建）

```
阶段1: node:16-alpine
  npm install（npmmirror 源）→ npm run build
阶段2: nginx:alpine
  COPY dist → /usr/share/nginx/html → EXPOSE 80
```

### 2.4 nginx.conf（挂载进前端容器）

```nginx
server {
    listen 80;
    server_name 8.137.114.176;          # 生产服务器 IP

    location /api/ {                    # 后端 API 反代
        proxy_pass http://backend:9090/api/;
        client_max_body_size 60m;       # 与后端上传限制一致
    }

    location / {                        # Vue history 路由回退
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }
}
```

### 2.5 数据卷

| 卷 | 挂载点 | 内容 |
| --- | --- | --- |
| cloudland-files | backend:/cloudland-files | 上传文件根目录（`FILE_STORAGE_ROOT`） |
| mysql-data | mysql:/var/lib/mysql | 数据库持久化 |
| redis-data | redis:/data | Redis 持久化 |

## 3. 环境变量参考

模板：[.env.example](../../.env.example)。全部变量在 [application.yml](../../src/main/resources/application.yml) 中有默认值。

### 3.1 数据库与缓存

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DB_URL` | `jdbc:mysql://localhost:3306/cloudland?...` | JDBC 连接串（Docker 内指向 `mysql:3306`） |
| `DB_USERNAME` / `DB_PASSWORD` | root / 123456 | MySQL 凭据 |
| `REDIS_HOST` / `REDIS_PORT` | localhost / 6379 | Redis 地址（Docker 内指向 `redis`） |
| `REDIS_PASSWORD` / `REDIS_DATABASE` / `REDIS_TIMEOUT` | 123456 / 0 / 1800000 | Redis 配置 |

### 3.2 认证与 CORS

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `JWT_SIGN_KEY` | change-me-in-production | **生产必须修改** |
| `JWT_EXPIRE` / `JWT_WEEK` | 604800000（7天） | token 有效期（ms） |
| `CORS_ALLOWED_ORIGINS` | `http://localhost:8080,http://127.0.0.1:8080` | 逗号分隔的允许源 |

### 3.3 邮件与万能验证码

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `MAIL_HOST` / `MAIL_PORT` | smtp.qq.com / 465 | SMTP 服务器 |
| `MAIL_USERNAME` / `MAIL_PASSWORD` | - | 发件邮箱与授权码 |
| `CODE_MASTER_ENABLED` | 本地 `true` / docker `false` | **万能验证码开关**：开启后登录/注册/找回密码的验证码填 `000000` 即可通过（测试便利）；生产必须 `false` |
| `CODE_MASTER_VALUE` | `000000` | 万能验证码值 |

### 3.4 支付宝（沙箱）

| 变量 | 说明 |
| --- | --- |
| `ALIPAY_APP_ID` | 沙箱应用 ID |
| `ALIPAY_PRIVATE_KEY` | 应用私钥 |
| `ALIPAY_PUBLIC_KEY` | 支付宝公钥 |
| `ALIPAY_NOTIFY_URL` | 异步回调（默认 `http://8.137.114.176/api/alipay/notify`） |
| `ALIPAY_RETURN_URL` | 同步回跳（默认 `http://8.137.114.176/user/myOrder`） |

> 网关固定为沙箱 `https://openapi-sandbox.dl.alipaydev.com/gateway.do`，切生产需改 application.yml。

### 3.5 文件存储

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `FILE_STORAGE_ROOT` | `D:/CloudLandFile` | 上传文件根目录（Docker 内为 `/cloudland-files`） |

## 4. 生产部署（CI/CD）

### 4.1 部署脚本 scripts/deploy.sh

生产路径：`/root/cloudland`，日志：`/var/log/cloudland-deploy.log`。流程：

```
1. flock /tmp/cloudland-deploy.lock 防并发部署
2. git fetch + checkout {branch} + reset --hard origin/{branch}
3. docker compose pull mysql redis（预拉基础镜像）
4. docker compose build --pull backend frontend
5. 停止宿主机 nginx（端口 80 冲突：systemctl stop/disable + pkill）
6. docker compose up -d --force-recreate --remove-orphans
7. 轮询 cloudland-frontend 容器状态（12 次 × 5s），失败则输出日志并退出
8. docker image prune -f 清理悬空镜像
```

### 4.2 Gitee Go 流水线

文件：[.gitee/workflows/cloudland-deploy.yml](../../.gitee/workflows/cloudland-deploy.yml)

- 触发：push 到 `main` 分支
- 通过 SSH 连接生产服务器 → `git fetch/checkout/reset` → 执行 `/bin/bash scripts/deploy.sh main`

### 4.3 手动部署

```bash
ssh <server>
cd /root/cloudland
bash scripts/deploy.sh main       # 或指定其他分支
```

## 5. Playwright E2E 测试

### 5.1 前置条件

**后端(9090) + 前端(8080) + MySQL + Redis 全部运行**，且 `vue/tests/helpers/redis.js` 需能直连 Redis（本地 6379）。测试账号由 `npm run test:ci` 自动种子化（seed.mjs，无需手工准备）。

### 5.2 配置要点（vue/playwright.config.js）

- baseURL：`http://localhost:8080`
- **workers: 1**（串行执行，避免数据竞争）
- retries：本地 1 次 / CI 2 次
- projects：`webkit`、`edge-ci`（无头，CI 用）、`edge-debug`（有头 + slowMo 800ms，本地观察用）；CI 执行 `npm run test:ci`（= webkit + edge-ci）
- 测试文件：`vue/tests/*.spec.js`；helpers 在 `vue/tests/helpers/`

### 5.3 常用命令

```bash
cd vue
npx playwright test                       # 全部测试
npx playwright test tests/login.spec.js   # 单文件
npx playwright test --project=webkit      # 仅 webkit
```

### 5.4 测试技巧（helpers）

- `redis.js`：ioredis 惰性单例直写 Redis 验证码，**绕过真实邮件收发**（连接参数支持 `TEST_REDIS_*` 环境变量）
- `cleanup.js`：调用管理员 API 清理测试产生的数据（API 地址支持 `TEST_API_BASE_URL`）
- `auth.js`：`loginByPassword` / `getAdminToken`（使用 seed.sql 种子管理员，不依赖演示数据）

> 后端无单元测试（`mvn test` 为空操作），E2E 是唯一自动化测试手段。

## 6. 常见问题排查

| 症状 | 排查方向 |
| --- | --- |
| 前端请求全部 401 | 检查请求是否带了过期 token；登录接口 URL 含 `login` 才免认证 |
| 跨域报错 | `CORS_ALLOWED_ORIGINS` 是否包含前端实际访问源 |
| 图片/文件 404 | `FILE_STORAGE_ROOT` 是否存在且有权写入；`/resource/**` 映射是否正确 |
| 验证码始终错误 | Redis 连接与密码；验证码 5 分钟 TTL 是否过期；键是邮箱还是手机号 |
| 支付后订单未变已支付 | `ALIPAY_NOTIFY_URL` 必须是**公网可达**地址（沙箱回调无法到达 localhost） |
| Docker 部署后端口 80 被占 | deploy.sh 会停宿主机 nginx；手动部署需先 `systemctl stop nginx` |
| MySQL 首次启动未建库 | `cloudland.sql` 挂载在 `/docker-entrypoint-initdb.d/`，仅在数据卷为空时执行；已有旧卷需 `docker volume rm` |
| Excel 导出下载空文件 | 后端容器内 `{FILE_STORAGE_ROOT}` 写权限；查看 OrderExporter 日志 |
