## 2. 后端分层架构

后端遵循经典三层 MVC：

```
Controller（REST 层）
    │  职责：参数接收（@RequestParam/@RequestBody/MultipartFile）、
    │        JSON 字符串 → POJO 反序列化（fastjson）、统一 Result 包装
    ▼
Service（业务层）
    │  职责：业务校验、事务（@Transactional）、跨表编排、
    │        文件落盘调用（FileUtil）、邮件发送（EmailUtils）、Redis 读写
    ▼
Mapper（数据层）
    │  职责：单表 CRUD 走 MyBatis-Plus BaseMapper（零 SQL），
    │        复杂查询走 XML 自定义 SQL（联表 + 动态条件 + 分页）
    ▼
MySQL
```

### 各层关键约定

- **Controller 只做"翻译"**：前端上传的 `land` / `product` / `user` 等参数是 **JSON 字符串**（`multipart/form-data` 混合提交），Controller 用 `JSON.parseObject(str, X.class)` 转对象后交给 Service
- **Service 返回 `Result`**：大部分 Service 方法直接返回统一响应对象（`new Result(code, data, msg)`），成功/失败码来自 [Code.java](../../src/main/java/com/cloudland/controller/result/Code.java)
- **VO 组装在 Service**：联表结果（如 LandVO 带类型名、联系人、图片列表）在 Service 层二次加工（再查 `cloudland_file` 表补充图片/资料路径）

前端请求链路：

```
组件 → axiosInstance（baseURL = APP_CONFIG.apiBaseUrl）
        → 请求拦截器：自动附加 headers.token
        → 后端
        ← 响应拦截器：读取 headers.updatedtoken 刷新本地 token；
                      HTTP 401/402/403 → clearAuthState() + 跳转首页
        ← 业务层：根据 response.data.code（constants/code.js）分支处理
```

## 4. 请求处理全流程（以"土地分页查询"为例）

```
1. 前端 LandView.vue
   axiosInstance.post('/land/page?pageNum=1&pageSize=5&land={...json}')
        │
2. CorsFilter（WebMvcConfig 注册）
   放行自定义头 token/remember/frond/code/contact/forgetPassword，
   暴露响应头 updatedToken
        │
3. MyInterceptor.preHandle（WebMvcConfig 注册，拦截 /**）
   /land/page 在 excludePathPatterns 白名单中 → 直接放行（免登录浏览）
        │
4. LandController.selectPage
   JSON.parseObject(landStr) → Land 对象
        │
5. LandServiceImpl.selectPage
   landMapper.selectByCondition(page, land)  ← LandMapper.xml 动态 SQL
   遍历结果再查 cloudland_file 表，补齐 imageFiles[] / landFiles
        │
6. MybatisPlusInterceptor（分页插件自动追加 LIMIT）
        │
7. 返回 Result{ code:10004, data:IPage<LandVO>, msg:"查询成功" }
```

## 6. 跨模块协作点（阅读代码时的线索）

| 协作点 | 位置 | 说明 |
| --- | --- | --- |
| 订单 ↔ 土地/产品 | [Order2ServiceImpl](../../src/main/java/com/cloudland/service/impl/Order2ServiceImpl.java) | 下单锁定土地（status 置 0）/扣减产品库存（num）；删单/定时清理时反向回滚 |
| 订单 ↔ 支付宝 | [AlipayController](../../src/main/java/com/cloudland/controller/AlipayController.java) + Order2ServiceImpl | 交易号 `CLD{timestamp}{userId}` ↔ orderIds 映射存 Redis 30 分钟；回调后批量置已支付 |
| 用户 ↔ 土地 | UserServiceImpl.delete | 删除用户前先把 `land.employee_id` 置 NULL 解除外键约束 |
| 文件 ↔ 土地 | LandServiceImpl + FileUtil + CloudLandFileMapper | 上传 → 落盘 → 压缩打包 → `cloudland_file` 表登记 type(0 图片/1 资料) |
| 前端 ↔ 后端状态码 | code.js ↔ Code.java | 两份镜像，新增状态码必须同步修改 |
| Redis ↔ 邮件 | UserServiceImpl.sendOutEmail / forgetPassword | 验证码 5 分钟 TTL，键为邮箱或手机号 |
