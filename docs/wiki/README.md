# Cloudland Code Wiki

Cloudland（云用地）是一个全栈土地/农产品订购平台，后端基于 **Spring Boot 2.7.14 + Java 8**，前端基于 **Vue 2.6**，数据层使用 **MySQL 8 + Redis 7**，支持支付宝沙箱支付与 Docker 一键部署。

## 快速了解

```
┌─────────────┐   HTTP(/api)    ┌──────────────┐   MyBatis-Plus   ┌────────┐
│  Vue 2.6    │ ──────────────> │ Spring Boot  │ ───────────────> │ MySQL  │
│  :8080/:80  │ <────────────── │    :9090     │                  └────────┘
└─────────────┘                 │              │   StringRedis    ┌────────┐
                                │              │ ───────────────> │ Redis  │
                                └──────┬───────┘                  └────────┘
                                       │ SMTP / 支付宝沙箱 / 本地文件系统
                                       ▼
```

- 后端端口 `9090`，context-path `/api`；前端开发端口 `8080`，生产环境由 Nginx 服务于 `80`
- 认证方式：自定义 JWT（请求头 `token`，响应头 `updatedToken`），不使用 Spring Security 全套
- 文件存储在项目外目录（默认 `D:/CloudLandFile`），通过 `/resource/**` 静态映射对外暴露
