# 01 项目概述

## 1. 项目简介

Cloudland（云用地）是一个土地/农产品订购平台，包含两大业务线：

1. **土地（用地）业务**：土地信息发布、分类型浏览（农用地/建设用地/商业用地等 6 类）、土地详情（图片 + 资料压缩包）、土地租赁下单
2. **产品业务**：农产品的展示、购物车、下单购买

平台角色分为三类（`user.power` 字段）：

| power | 角色 | 说明 |
| --- | --- | --- |
| 0 | 客户 | 前台浏览、下单、购物车、个人中心 |
| 1 | 员工 | 作为土地代理人（`land.employee_id`）被指派 |
| 2 | 管理员 | 后台管理用户/土地/产品/订单、消息推送 |

用户状态（`user.status`）：`1` 激活，`0` 禁用（被封禁后所有需认证接口返回 HTTP 403）。

## 4. 关键配置入口

- 后端主配置：[application.yml](../../src/main/resources/application.yml)，所有敏感项均使用 `${ENV_VAR:default}` 形式，可被环境变量覆盖
- 本地私密覆盖：`config/application-local.yml`（gitignored，经 `spring.config.import: optional:file:./config/application-local.yml` 加载）
- 前端配置：`vue/src/config/app.js` 读取 `VUE_APP_API_BASE_URL` / `VUE_APP_FRONTEND_BASE_URL`，统一导出 `APP_CONFIG`
- 环境变量模板：[.env.example](../../.env.example)

## 5. 已知陷阱（开发必读）

1. **groupId 拼写**：`pom.xml` 中 groupId 历史上拼写为 `com.couldland`，已于 2026-09-01 修正为与 Java 包名一致的 `com.cloudland`（同时 `<name>` 由 `Couldland` 改为 `Cloudland`）；本项目为单模块工程、无 `mvn deploy`，坐标变更不影响构建/部署
2. **Order2 而非 Order**：订单实体叫 `Order2`，表名 `order2`，避免 SQL 关键字 `ORDER` 冲突
3. **Interceptor 目录大写 I**：`com.cloudland.Interceptor` 不符合 Java 包命名规范，但被 `WebMvcConfig` 引用，保持原样
4. **UI 库说明**：README 曾写"Bootstrap 5"，实际 UI 库为 Element UI 单库 + Bootstrap 4.6.1 纯 CSS（`assets/css/HomeView/bootstrap.min.css`），无 Bootstrap JS 组件
5. **HTTP 状态码被复用**：401=未认证、402=权限变更、403=账号禁用**或**权限不足（以响应头 `X-Forbidden-Reason` 区分 status/power），**不是**标准语义；前端 [interceptor.js](../../vue/src/request/interceptor.js) 依赖这套约定
6. **令牌头名称**：请求头是 `token`（不是 `Authorization`），刷新令牌在响应头 `updatedToken`（axios 读取时小写 `updatedtoken`）
7. **无后端单测**：`mvn test` 是空操作；只有前端 Playwright E2E
8. **application-local.yml 含真实凭据**：邮件密码、支付宝密钥，**严禁提交**
9. **支付仅支持支付宝**：曾引入微信支付依赖但从未集成，已在死代码清理中移除；实际支付只走支付宝沙箱
10. **land.status 语义反直觉**：**1 = 可租用，0 = 已占用（已租出/被锁定）**。下单时校验 `status==1` 后置 0，删单/超时清理回滚为 1；建表注释只写"状态"，阅读代码时极易弄反
11. **土地列表查询 INNER JOIN 代理人**：[LandMapper.xml](../../src/main/resources/com/cloudland/mapper/LandMapper.xml) 的列表 SQL 用 `INNER JOIN user ON employee_id`——**未指派代理人的土地不会出现在前台/后台列表中**（测试数据均带代理人）；`selectById` 同理
