# 04 前端模块详解

前端工程位于 `vue/`，Vue 2.6 + Vue CLI 5，UI 为 **Element UI**（辅以 Bootstrap 4.6.1 纯 CSS 工具类）。

## 1. 工程配置

### 1.1 package.json 脚本

```bash
npm run serve   # 开发服务器 http://localhost:8080
npm run build   # 生产构建
```

### 1.2 环境变量（.env.local / .env.production）

| 变量                          | 默认值                      | 说明                                                                       |
| --------------------------- | ------------------------ | ------------------------------------------------------------------------ |
| `VUE_APP_API_BASE_URL`      | `http://localhost:9090`  | 后端地址（仓库自带的 `vue/.env.production` 固定为 `http://8.137.114.176/api`，生产构建时生效） |
| `VUE_APP_FRONTEND_BASE_URL` | `window.location.origin` | 前端地址（拼接找回密码链接用）                                                          |

### 1.3 src/config/app.js — APP\_CONFIG

文件：[app.js](../../vue/src/config/app.js)

```js
APP_CONFIG = {
  apiBaseUrl,                      // 规范化（去尾斜杠）后的后端地址
  frontendBaseUrl,
  resourceUrls: {                  // 静态资源统一拼接（禁止硬编码后端地址）
    userFile:   `${apiBaseUrl}/resource/userFile/`,
    landFile:   `${apiBaseUrl}/resource/landFile/`,
    productFile:`${apiBaseUrl}/resource/productFile/`,
  },
  forgetPasswordPath: `${frontendBaseUrl}/ForgetPassword/`,
}
```

同时挂载到 `window.__APP_CONFIG__`。图片显示统一：`APP_CONFIG.resourceUrls.landFile + path`。

## 2. 请求层（src/request/）

### 2.1 axiosInstance.js

创建 axios 实例，`baseURL = APP_CONFIG.apiBaseUrl`，超时 **600 秒**（适配大文件上传）。

### 2.2 interceptor.js — 拦截器

文件：[interceptor.js](../../vue/src/request/interceptor.js)，`setupInterceptors()` 在 main.js 安装（幂等，只装一次）。

**请求拦截器**：自动附加 `config.headers.token = getStoredToken()`。

**响应拦截器**：

| 场景                                          | 处理                                                              |
| ------------------------------------------- | --------------------------------------------------------------- |
| 响应头含 `updatedtoken`                         | `persistToken(updatedToken, hasPersistentToken())` 静默刷新本地 token |
| HTTP 401                                    | 清登录态 + 跳转首页（未认证）                                                |
| HTTP 402                                    | `Message.warning("账号权限发生变更！")` + 清登录态 + 跳首页                     |
| HTTP 403（`X-Forbidden-Reason: status` 或无该头） | `Message.error("账号已被禁用！")` + 清登录态 + 跳首页                         |
| HTTP 403（`X-Forbidden-Reason: power`）       | `Message.error("您没有权限访问该功能！")`——**保留登录态**（仅权限不足）                |
| HTTP 500                                    | console.error                                                   |

> 注意文件头注释：**HTTP 状态码**（网络层，拦截器处理）与**业务状态码**（`response.data.code`，业务代码处理）是两套体系，勿混淆。

## 3. 认证工具（src/utils/auth.js）

文件：[auth.js](../../vue/src/utils/auth.js)

| 函数                                                                                   | 说明                                                                                                   |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `createEmptyUser()`                                                                  | 空用户模板（token 验证登录时作为请求体占位）                                                                            |
| `hasPersistentToken()`                                                               | localStorage 是否有 token（"记住我"）                                                                        |
| `getStoredToken()`                                                                   | **优先 sessionStorage，其次 localStorage**（过滤 'null' 字符串）                                                 |
| `persistToken(token, remember)`                                                      | remember=true 写 localStorage；始终写 sessionStorage                                                      |
| `clearAuthState()`                                                                   | 清 localStorage.token + sessionStorage 的 token/uid/userID，并失效登录态缓存                                    |
| `fetchCurrentUser(frond)`                                                            | 静默登录：带 token 调 `/user/login`，code=20005 → 更新 token 并返回 user；code=20003（令牌过期）→ 清登录态                   |
| `loginWithPassword(user, {frond, remember, code})`                                   | 密码登录封装，成功后持久化 token（msg 字段即新 token）并写登录态缓存                                                           |
| `invalidateLoginState()` / `getCachedLoginState()` / `setCachedLoginState(loggedIn)` | **登录态内存缓存（供路由守卫）**：校验结果缓存 5 分钟（TTL），登录成功/登出/清 token 时主动失效——避免每次导航都请求 `/user/login`；服务端封号等变更最迟 5 分钟生效 |

**token 存储策略**：sessionStorage（关标签页失效）为主，勾选"记住我"时额外写 localStorage（7 天 JWT 有效期，`jwt.week`）。

### 5.2 路由守卫 beforeEach

```
每次导航 → isUserLoggedIn()：
  取 token（sessionStorage/localStorage）→ 无 token 直接 false
  → 命中登录态缓存（5 分钟 TTL）→ 直接返回缓存结果
  → 未命中：POST /user/login（空 user + token/remember/frond 头）
    → res.code === 20005 视为已登录并写缓存

未登录访问 PROTECTED_BACKEND_PATHS（/backend/land | customerA | customerB | employee）
  → Message.warning('未登录！') + 跳 '/'
未登录访问 /user/** → Message.warning('请先在首页右上方登录!') + 跳 '/'
其余放行（其余后台页面由各页面内部的 openCheck 自行校验）
```

> **性能说明**：守卫原先每次导航都 POST `/user/login` 校验 token（服务端实时校验，导航密集时请求放大）；现已配合 [auth.js](../../vue/src/utils/auth.js) 的登录态缓存（TTL 5 分钟，登录成功/登出/清 token 时失效），缓存命中时不发请求。

### 5.3 scrollBehavior / afterEach

- `scrollBehavior`：路由切换回到顶部；浏览器前进/后退恢复原滚动位置

- `afterEach`：`document.title = to.meta.title || '云用地'`

## 6. 共享组件（src/components/）

### 6.1 NavBar.vue — 统一顶部导航（原 Top.vue 与 Top2.vue 合并）

文件：[NavBar.vue](../../vue/src/components/NavBar.vue)，通过 `mode` prop 切换两种形态：

| mode       | 使用场景                    | 形态                                                                                                            |
| ---------- | ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| `home`     | 首页（`frontend/MainView`） | 透明导航（滚动变品牌绿，`assets/js/script.js` 的 `myFunction()`）+ 锚点菜单（首页/介绍/功能/联系我们/订阅/后台）+ 登录图标 + 内嵌 `<LoginForm frond>` |
| `page`（默认） | 列表/详情/个人中心/后台           | 固定品牌绿顶栏 + 首页链接 + 用户入口（未登录显示"未登录"）                                                                             |

- 两种模式都在 mounted 时 `fetchCurrentUser()` 恢复登录态，并把 userId 写入 sessionStorage（详情页加购依赖）

- 已登录态：头像（`APP_CONFIG.resourceUrls.userFile` + img）+ 用户名展示

- `beforeDestroy` 时清理滚动事件监听

### 6.2 LoginForm.vue — 统一登录/注册表单（原 Top.vue 与后台 MainView 三份复制代码合并）

文件：[LoginForm.vue](../../vue/src/components/LoginForm.vue)，通过 `frond` prop 区分前后台：

| frond   | 场景                 | 能力                                                              |
| ------- | ------------------ | --------------------------------------------------------------- |
| `true`  | 前台（NavBar home 模式） | 登录 + 注册（用户名/手机号/密码/年龄/QQ邮箱/省市区级联/详细地址/验证码，正则校验）+ 忘记密码 + 记住我，可关闭 |
| `false` | 后台                 | 仅登录（提示"需要二级账号"），不可关闭                                            |

- 登录成功后 `emit('login-success', user)`，由父组件（NavBar/后台 MainView）处理各自后续逻辑

- 验证码发送按钮带倒计时防重

- 调用 `utils/auth.js` 的 `loginWithPassword()` 完成登录

## 8. Playwright E2E 测试（vue/tests/）

- 配置：`vue/playwright.config.js`，baseURL `http://localhost:8080`，**workers=1 串行**，retries 本地 1 次 / CI 2 次；reporter 为 `html` + `junit`（输出 `test-results/junit.xml`，供 CI 汇总）

- 项目：`webkit`、`edge-ci`（无头 Edge，CI 用）、`edge-debug`（有头 + slowMo 800ms，本地调试用）；快捷脚本 `npm run test:ci`（webkit + edge-ci）/ `npm run test:debug`（edge-debug）

- 运行前提：**后端 + 前端 + MySQL + Redis 全部运行中**

- 常用命令：

  ```bash
  cd vue
  npx playwright test                    # 全部
  npx playwright test tests/login.spec.js  # 单文件
  ```

- Helpers（`tests/helpers/`）：

  - `redis.js`：用 ioredis 直接向 Redis 写验证码，绕过真实邮件

  - `cleanup.js`：调管理员 API 清理测试数据

## 9. main.js 装配顺序

```
Element UI 按需引入（约 26 个组件 + $message/$confirm/$notify/$loading 服务，
替代全量 Vue.use(ElementUI)，打包体积从 ~650KB 降至实际所需）
→ 全局样式分层引入（顺序即层叠顺序）：
   1. styles/tokens.css（全站唯一色值来源）
   2. element-ui theme-chalk 基础 + 按需组件样式
   3. 模板基础样式 style.css + Bootstrap 工具类
   4. styles/element-overrides.css（Element 品牌化覆盖）+ styles/shared.css（跨组件共享）
→ Vue.prototype.$appConfig = APP_CONFIG → setupInterceptors()（请求/响应拦截）
→ new Vue({router, render: App}).$mount('#app')
```
