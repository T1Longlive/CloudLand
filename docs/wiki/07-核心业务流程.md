# 07 核心业务流程

## 1. 注册流程

```
前端注册表单（LoginForm.vue 对话框）
  │ multipart/form-data: userIcon(可选) + user(JSON字符串)
  │ 请求头 code = 邮箱验证码（可选开启）
  ▼
POST /user/register
  │
  ├─ code 头存在？→ isCodeValid 统一校验（Redis 真实验证码或万能码 000000，错→30003），通过后删除
  ├─ 手机号查重（存在→20007）
  ├─ 邮箱查重（存在→30004）
  ├─ 头像落盘（无→默认 basic.png）
  ├─ BCrypt 加密密码
  └─ INSERT user → 20006
```

## 2. 登录与 token 生命周期

```
密码登录（可带邮箱验证码）                 token 静默续期
────────────────────────                ────────────────────────
POST /user/login                        页面加载/路由守卫
  body: {phone, password}               POST /user/login
  headers: remember, frond                body: 空 user 对象
  headers: code(可选)                     headers: token, remember, frond
        │                                       │
        ▼                                       ▼
  校验验证码(可选,isCodeValid)→查用户        解析JWT→比对DB→status校验
  →BCrypt比对(支持万能码000000)
        │                                       │
        └───────────────┬───────────────────────┘
                        ▼
             签发新 JWT（remember ? 7天 : expire）
             返回 Result{data:用户, code:20005, msg:新token}
             响应头 updatedToken = 新token
                        │
                        ▼
             前端 persistToken()
             sessionStorage 必写；remember 时 localStorage 也写
```

**token 失效路径**：

| 触发 | 结果 |
| --- | --- |
| 超过有效期 | 后端解析失败 → HTTP 401 → 前端清登录态跳首页 |
| 账号被禁用（status→0） | 拦截器 HTTP 403 |
| power 被修改 | 拦截器 HTTP 402（提示权限变更） |
| 用户主动登出 | 前端 clearAuthState()（无服务端黑名单，token 在有效期内仍有效） |

## 3. 找回密码（两阶段）

```
阶段一：申请重置链接
  POST /user/forgetPassword {phone} + path(前端页面地址)
    → 按手机号查用户
    → 生成验证码存 Redis（键=手机号，5分钟）
    → 发邮件：链接 = path + code + "-" + userId
    → 用户点击邮件链接 → 前端 /ForgetPassword/:id 路由（:id = "code-userId"）

阶段二：落地页 /ForgetPassword/:id（:id = "code-userId"）
  2a. 页面加载 openCheck：POST /user/forgetPassword {id, path=code}
    → isCodeValid(phone, code) 统一校验（Redis 真实验证码或万能码 000000）
    → 通过 → 10003 展示改密表单；失败 → 跳回 /user
  2b. 提交新密码 updateUser：POST /user/forgetPassword {id, password}
    请求头 forgetPassword: true（走改密分支，跳过验证码）
    → 新旧密码查重（相同→20010）
    → BCrypt 加密更新 → 10003
```

## 4. 土地管理流程（含文件）

### 4.1 新增土地

```
后台 LandView 上传表单
  multipart: landFiles[](资料) + imageFiles[](图片) + land(JSON)
        ▼
POST /land → LandServiceImpl.save
  1. INSERT land（拿自增 id）
  2. FileUtil.defineDirectory(id, landFiles, imageFiles, null, null)
     ├─ 资料文件 → 存 Land_{id}/CloudLandFile/ 临时目录
     │    → zip 压缩为 "云用地_{id}{6位码}.zip" 至 Land_{id}/
     │    → 删除临时目录
     └─ 图片 → 重命名 Img_{id}_{6位码}.{ext} → Land_{id}/Images/
  3. cloudland_file 表登记：
     type=1 → zip 文件名（一条）
     type=0 → 每张图片（多条）
  4. 返回 10001
```

### 4.2 更新/删除

- 更新：传了 landFiles → 删旧 zip 文件与记录；传了 imageFiles → 清空 Images 目录与记录；再复用 save
- 删除：`DELETE /land {ids}` → 删 DB（cloudland_file 级联删）+ 删 `Land_{id}` 整目录

### 4.3 浏览（免登录）

`POST /land/page` / `GET /land/{id}` → `LandMapper.selectByCondition` 三表联查（land ⋈ land_type ⋈ user×2）→ Service 补图片列表与资料路径 → 前端拼 `APP_CONFIG.resourceUrls.landFile + "Land_{id}/Images/" + path` 显示。

## 5. 订单生命周期

```
                    ┌──────────────┐
                    │   未支付 0    │◄──── addOrder 创建
                    └──────┬───────┘
              支付成功/后台 │        │ 每日0点 OrderClear
              手动确认     │        │ (超时自动清理)
                    ┌──────▼───────┐
                    │   已支付 1    │
                    └──────┬───────┘
              用户删除(软删del=1)  后台退单
                    ┌──────▼───────┐
                    │   已退单 2    │
                    └──────────────┘
```

### 5.1 下单 addOrder（土地 vs 产品）

```
POST /order {pId, num, uId}
  ├─ 归属校验：普通用户(power=0)强制 uId=登录用户（防替他人下单）；员工/管理员可代录
  ├─ num == -1（土地订单）
  │    校验 land.status == 1（可租）？否 → 10005
  │    land.status → 0（锁定）
  └─ num > 0（产品订单）
       校验 product.num >= order.num 且 status==1？否 → 10005
       product.num -= order.num（扣库存）
  设置 createTime=now, status=0, del=0 → INSERT → 10001
```

### 5.2 删单 deleteOrder

```
DELETE /order/{id}
  ├─ 归属校验：普通用户(power=0)仅可删自己的订单（他人订单→20008）；员工/管理员不受限
  ├─ 已支付（status==1 且 payTime≠null）→ 软删 del=1（保留记录）
  └─ 未支付 → 回滚资源（土地 status→1 / 产品 num+=num）→ 物理删除
```

### 5.3 超时清理 OrderClear

`@Scheduled(cron = "0 0 0 * * ?")` 每日 0 点：所有 `status==0` 订单回滚资源并物理删除。

## 6. 支付宝支付流程

```
前端 MyOrder 勾选订单（仅 status=0 可选）→ POST /alipay/pay {orderIds[], totalAmount, userId}
        │
        ▼
AlipayController.pay
  1. calcTotalAmount：服务端重算金额（前端 totalAmount 仅记日志比对，不作为支付金额）
     ├─ 订单不存在 / 状态非未支付 → 拒绝（防重复支付）
     ├─ 土地订单（num=-1）→ + land.price
     └─ 产品订单 → + product.price × num
  2. 生成交易号 outTradeNo = "CLD" + 时间戳 + 登录用户ID（ATTR_USER_ID）
  3. saveTradeMapping：归属校验（power=0 仅限本人订单）+ Redis SET
     alipay:trade:{outTradeNo} = orderIds JSON（30分钟）
  4. alipayClient.pageExecute(AlipayTradePagePayRequest)
     bizContent: {out_trade_no, total_amount(服务端重算值，两位小数),
                  subject:"云用地订单支付", product_code:"FAST_INSTANT_TRADE_PAY"}
     notifyUrl / returnUrl 来自 alipay.* 配置
  5. 返回 Result{data: 支付宝表单HTML} → 前端 document.write 提交跳转支付宝
        │
        ▼
   ┌─ 用户在支付宝页面付款 ─┐
   │                       │
   ▼                       ▼
同步回跳               异步回调
GET /alipay/return     POST /alipay/notify
  主动查单              RSA2 验签(rsaCheckV1)
  TRADE_SUCCESS?          ├─ 验签通过且 TRADE_SUCCESS
  ├─ 是 → handlePaySuccess → handlePaySuccess
  └─ 否 → "支付未完成"       │
                             ▼
                  handlePaySuccess(outTradeNo) [@Transactional]
                    1. Redis GET alipay:trade:{outTradeNo} → orderIds
                    2. updateOrder(orderIds, status=1, time=true) 批量置已支付
                    3. Redis DEL 该键（防重复处理）
                    4. 返回 "success" 给支付宝
```

**幂等性说明**：return 与 notify 都可能触发 handlePaySuccess；Redis 键删除后二次调用会因 `json == null` 直接 return，天然幂等。

## 7. 购物车流程

```
加入购物车：POST /user/addTrolley {pId, num(-1或数量), uId}
查看：POST /user/trolley {userId}
  → 按 u_id 倒序查 trolley
  → 逐条组装 TrolleyVo：
     num=-1 → 查 Land + 首图（cloudland_file type=0 第一张，加 Land_{id}/Images/ 前缀）
     num>0  → 查 Product（价格/库存/图片）
删除：DELETE /user/trolley/{id}
结算：前端把购物车条目逐个 POST /order 下单（可合并发起 /alipay/pay 支付）
```

## 8. 消息与订阅流程

```
留言（免登录）：
  首页留言表单 → POST /msg {name, mail, phone, msg}
  → 同手机号留言数 > 9 拒绝（上限10条）
  → 补 sendTime → INSERT

订阅（免登录）：
  POST /msg/mail {mail} → 查重 → INSERT msg_send

后台推送：
  PushMsg 页面 → POST /msg/push (pushMsg 文本)
  → 遍历 msg_send 全部邮箱 → EmailUtils 群发 HTML 邮件
  → 返回 30001 "推送成功"
```

## 9. 订单 Excel 导出流程

```
后台订单页 → POST /order/download?order={JSON条件}
  │
  ▼
Order2ServiceImpl.getOrder
  1. num==-1（土地单）→ orderMapper.selectOrder(order)（联 land/user）+ 补土地首图
     否则（产品单）   → orderMapper.selectOrder2(order)（联 product/user）
  2. OrderExporter.exportToExcel(orderVOS, type)
     POI XSSF 生成 xlsx，写至 {FILE_STORAGE_ROOT}/云用地_用地订单.xlsx 或 _产品订单.xlsx
  3. DownloadUtil.getFile(name, response) 流式下载
```

> 导出文件写在服务器存储根目录再下载（非内存流），并发导出会互相覆盖同名文件——单人后台使用场景下的取舍。

## 10. 文件存储目录全景

```
{FILE_STORAGE_ROOT}（默认 D:/CloudLandFile，Docker 内 /cloudland-files）
├── UserIcon/                          ← /resource/userFile/**
│   ├── basic.png                      （默认头像）
│   └── userIcon_{UUID}.{ext}
├── LandFile/                          ← /resource/landFile/**
│   └── Land_{id}/
│       ├── 云用地_{id}{6位码}.zip      （资料压缩包，cloudland_file type=1）
│       └── Images/
│           └── Img_{id}_{6位码}.{ext} （图片，cloudland_file type=0）
├── Product/                           ← /resource/productFile/**
│   └── product_{UUID}.{ext}
├── 云用地_用地订单.xlsx                 （导出产物）
└── 云用地_产品订单.xlsx                 （导出产物）
```

URL 映射规则（WebMvcConfig）：`/api/resource/{userFile|landFile|productFile}/**` → 上述目录，**静态资源免认证**。
