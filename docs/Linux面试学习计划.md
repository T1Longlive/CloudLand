# Linux 面试一周学习计划

> 目标：一周内（D1~D7）快速建立 Linux 面试所需的**基本盘**。核心理念配合 AI 时代：
> - **A 层**：高频命令与权限，必须"闭眼能敲"（死记 + 手敲）
> - **B 层**：原理概念，必须"口头讲得清"（懂原理，不看细节）
> - **C 层**：冷门功能，只需"知道存在 + 用什么查"，语法交给 AI / `--help`
>
> 每天的节奏：**概念 10 分钟 + 命令实操 20~30 分钟 + 自测 5 分钟**。全程 1~1.5 小时。

---

## 一、三层学习策略总览

| 层级 | 策略 | 占力 | 面试角色 |
| --- | --- | --- | --- |
| **A 死记+手敲** | 核心命令集，肌肉记忆 | 60% | 保底 |
| **B 懂原理** | 概念口头讲清，命令看会 | 30% | 拿分 |
| **C 知道存在** | 只记"有这功能、用什么查" | 10% | 做门面 |

### A 层 · 必须死记手敲的命令集（高频）

```bash
ls cd pwd mkdir touch rm cp mv cat tail head
grep find ps top kill
chmod chown          # 数字权限 754 / 777 / 600 / 644
tar -czvf / -xzvf
ssh scp
systemctl status/restart/enable
df du free
ss -lntp / netstat -lntp
echo 变量、管道 |、重定向 > >>、后台 &
```

### B 层 · 必须能"口头讲清"的原理（面试主战场）

1. 一切皆文件
2. FHS 目录结构：`/etc` 配置、`/var` 日志、`/home` 用户、`/usr` 程序、`/tmp` 临时、`/opt` 程序
3. 软链接 vs 硬链接
4. 进程 vs 线程、僵尸/孤儿进程
5. 权限模型（一行 `ls -l` 里的三组 rwx）
6. 挂载与 inode
7. systemctl 按"名字"管服务，对比 raw kill

### C 层 · 知道存在即可（面试提一嘴不深入）

- awk / sed（会做文本处理，不背复杂脚本语法）
- iptables / ufw / SELinux（知道是防火墙/强制访问控制机制）
- LVM / RAID（磁盘逻辑卷和冗余方案）
- vim 只有基本键位（进入/编辑/保存/退出）
- 内核编译 / modprobe 模块加载
- 性能工具 iostat / sar / vmstat（知道分别看磁盘/CPU/内存）

## 二、每日细分计划

---

### D1 · Linux 哲学 + 文件/目录操作（A 层手感）

**目标**：建立"一切皆文件"心智 + 文件操作命令闭眼能敲。
**环境**：有 Linux/云主机直接用；没有就用 Docker：`docker run -it alpine sh`。

| 步骤 | 内容 | 任务 | 验收条件 |
| --- | --- | --- | --- |
| 1 | 三个基本概念 | 记住：①一切皆文件 ②多用户 ③命令=带参数的程序 | 能用自己的话复述这三点 |
| 2 | 漫游 `pwd cd ls` | 用 `ls -l` / `ls -a` 逛 `/home /etc /var /tmp` | 能说出每个目录大致放什么 |
| 3 | 增删改 `mkdir touch cp mv rm` | 建 `/tmp/d1`，copy 目录过去再删掉 | 全程不查手册敲完 |
| 4 | 查看 `cat tail -f head` | 用 `tail -f <某日志>` 看实时输出 | 能用 `tail -f` 跟读日志 |
| 5 | 综合练习 | 把 `/etc/hosts` 复制到 `/tmp/d1/` 改名为 `hosts.bak` | 命令执行成功且名字正确 |

**自测（参考答案）**
1. `ls -la` 最前面的 `-rw-r--r--` 大致什么意思？
   → 第一个 `-` 表示普通文件；后 9 位分三组：属主 rw、属组 r、其他 r。
2. `tail -f` 和 `tail` 区别？
   → `-f`（follow）持续跟读文件新增内容，用于实时看日志；`tail` 只看末尾固定行数。

---

### D2 · 权限 + 用户/组 + 链接（A+B）

**目标**：说清 `754`；分辨软/硬链接（必考原理）。

| 步骤 | 内容 | 任务 | 验收条件 |
| --- | --- | --- | --- |
| 1 | rwx 三组含义 | 背下 `r=4 w=2 x=1`，三组=属主/属组/其他 | 能把任意 `rwx` 串转成数字 |
| 2 | `chmod chown` | 把 D1 文件改成 `644`、`755`，`chown` 换属主 | 命令执行，`ls -l` 能看到变化 |
| 3 | 用户/组 | `useradd tom`、`passwd tom`，理解 `su`/`sudo` | 能说出普通用户为什么少权限 |
| 4 | 链接原理 | 硬链接=同一 inode 多名字；软链接=指向路径 | 能口头讲清两者区别 |
| 5 | 实操对比 | 建文件后做 `ln`(硬) 和 `ln -s`(软)，删源观察 | 观察硬链仍可用、软链失效 |

**自测（参考答案）**
1. `754` 分别给谁什么权限？
   → 属主 7=rwx，属组 5=rx，其他 4=r。
2. 软链和硬链接删了源会怎样？
   → 软链失效（指向不存在路径）；硬链照样可用（引用同一 inode）。
3. 脚本 `permission denied` 怎么办？
   → `chmod +x 脚本`（脚本本质是文本，缺 x 无法直接 `./` 执行）。

> 关联项目：`scripts/deploy.sh` 用 `bash` 执行；手动部署也常需 `chmod +x`。

---

### D3 · 进程 + 系统服务 + 日志（A，最贴部署）

**目标**：进程看/杀/放后台 + `systemctl` 管服务 + 日志查找。

| 步骤 | 内容 | 任务 | 验收条件 |
| --- | --- | --- | --- |
| 1 | 什么是进程 | 程序=静态文件，进程=运行实例，有 PID/PPID | 能讲清程序与进程区别 |
| 2 | `ps top` | `ps -ef`、`top` 找吃 CPU/内存的进程 | 能在 `top` 里说出列含义 |
| 3 | `kill` `nohup &` | 启 `sleep 1000` 再 `kill`；`nohup 命令 &` 后台 | 能杀掉进程、能放后台 |
| 4 | `systemctl` | `systemctl status/restart/enable nginx` | 能说 systemctl 与 kill 区别 |
| 5 | 日志 | `/var/log/`、`journalctl -u nginx` | 能找到并查看服务日志 |

**自测（参考答案）**
1. 服务挂了不重启，怎么排查？
   → `systemctl status` 看状态 → `journalctl -u 服务` 看日志。
2. `kill -9` 和 `kill`（15）区别？
   → `-9` SIGKILL 强制杀，不给清理机会；`kill` 默认 SIGTERM 请求正常终止。
3. 想开后台任务不怕会话退出？
   → `nohup 命令 > out.log 2>&1 &`。

> 关联项目：deploy.sh 停宿主机 nginx 用的正是 `systemctl stop` + `pkill -x nginx`。

### D4 · 网络 + 远程（A+B）

**目标**：看端口、连远程、传文件，找"谁占用了端口"。

| 步骤 | 内容 | 任务 | 验收条件 |
| --- | --- | --- | --- |
| 1 | 网络基础 | 理解 IP、端口、"端口=门的编号" | 能解释 80/9090 端口含义 |
| 2 | `ss -lntp` / `netstat -lntp` | 看监听端口和对应进程 | 能说出每个参数含义 |
| 3 | `ping curl` | `ping` 测连通、`curl localhost:9090/xxx` | 能用 curl 验接口 |
| 4 | `ssh scp` | `ssh user@host` 登录、`scp` 传文件 | 能远程登录并传文件 |
| 5 | 防火墙(思想) | 知道 iptables/ufw 是开关端口，会 `ufw allow 80` | 不背规则，能说清用途 |

**自测（参考答案）**
1. 找 9090 端口被谁占用？
   → `ss -lntp | grep 9090`（或 `netstat -lntp`）。
2. 你项目里 80 和 `/api` 反代对应哪个服务？
   → nginx 反代到 backend（`proxy_pass http://backend:9090`）。
3. `-t -l -n -p` 各什么意思？
   → TCP / 仅监听 / 数字形式显示 / 进程信息。

### D5 · 管道组合 + 定时任务 + 环境变量（A+B）

**目标**：会用 `| grep/find` 组合；懂 cron；懂 PATH。

| 步骤 | 内容 | 任务 | 验收条件 |
| --- | --- | --- | --- |
| 1 | 管道思想 | `命令A | 命令B` = A 输出流入 B | 能口头解释管道 |
| 2 | `grep find` | 日志搜关键词 `grep -n`；`find / -name "*.log"` | 能用两种方式找到目标 |
| 3 | 组合实战 | 搜日志里带 ERROR 的最近 20 行 | 命令结果符合预期 |
| 4 | 重定向/环境变量 | `> >>`、`echo $PATH`、`export`、`source` | 能解释 `>` 与 `>>` 区别 |
| 5 | `cron` | `crontab -e` 写一行 `* * * * * 命令` | 能说出 5 字段含义 |

**自测（参考答案）**
1. `ps -ef | grep nginx` 是干嘛？
   → 列出所有进程，再筛选出含 nginx 的行。
2. cron 的 5 个 `* * * * *` 代表？
   → 分 时 日 月 周。
3. `>` 和 `>>` 区别？
   → `>` 覆盖写，`>>` 追加写。

> 关联项目：`@Scheduled(cron = "0 0 0 * * ?")` 即服务端每天 0 点清理订单——可顺势讲"后端定时任务怎么定"。

### D6 · 磁盘/内存 + 打包解压（A+B）

**目标**：看磁盘满没满、找大文件、打包传文件（排障常考）。

| 步骤 | 内容 | 任务 | 验收条件 |
| --- | --- | --- | --- |
| 1 | `df du free` | `df -h`、`du -sh *`、`free -h` | 能读磁盘和内存占用 |
| 2 | 磁盘满排查 | 找满分区 → 找大文件 → 清理 | 能走完排查三步 |
| 3 | `tar` 打包 | `tar -czvf` 压缩 / `-xzvf` 解压 | 能打出并解开包 |
| 4 | 挂载/inode 概念 | 理解"磁盘要 mount"，inode=文件身份证 | 只讲清概念不实操分区 |
| 5 | 综合演练 | 把练习文件 `tar` 打包再 `scp` 传 | 全流程跑通 |

**自测（参考答案）**
1. 磁盘 100% 第一步干嘛？
   → `df -h` 找出满的分区。
2. 给人传整个文件夹？
   → `tar -czvf 包.tar.gz 目录` 再 `scp`。
3. `df` 和 `du` 区别？
   → `df` 看文件系统/分区整体占用；`du` 看具体目录/文件大小。

## 三、高频面试问答全集（含参考答案）

| 问 | 参考答案 |
| --- | --- |
| 你用过哪些 Linux 命令？怎么排障？ | 例：`ss -lntp` 找端口、`tail -f` 看日志、`top` 看负载、`docker logs` 看容器日志——拿自己项目当案例 |
| 怎么找占用的端口？ | `ss -lntp` 或 `netstat -lntp`，再用 `kill -9 PID` 清理 |

| 软硬链接区别？ | 硬链接指向同一 inode（删源仍可用）；软链接指向路径（删源失效）|
| 怎么让服务开机自启？ | `systemctl enable 服务` |
| 磁盘满了怎么办？ | `df -h` 找满分区 → `du -sh *` 找大文件 → 清日志/临时文件 |
| 进程和程序区别？ | 程序是静态文件，进程是运行中的实例（有 PID）|
| `kill -9` 与 `kill` 区别？ | -9 强杀，默认 15 请求正常终止 |
| `> ` 和 `>>` 区别？ | 覆盖 / 追加 |
| 脚本 permission denied 怎么办？ | `chmod +x`（脚本是文本，缺 x 不能直接 `./`）|
| 怎么实时看日志？ | `tail -f 文件` 或 `journalctl -f` |
| 没有 x 的文本文件能读吗？ | 能读，但不能当程序执行 |

## 四、加分案例（贴合你的云用地项目）

把这三句话讲熟即是加分项：
```
1. 部署：bash scripts/deploy.sh → 停宿主机 nginx → docker compose up -d
2. 排障：ssh 上服务器 → ss -lntp 看 80/9090 → docker logs 看容器 → tail -f /var/log/cloudland-deploy.log
3. 权限/服务：systemctl status nginx 判断宿主机服务；chmod 给脚本执行权限
```
