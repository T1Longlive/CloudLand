## D1 · Linux 哲学 + 文件/目录操作（A 层手感）

### 任务
- [ ] 复述三大概念：一切皆文件 / 多用户 / 命令=带参数的程序
- [ ] 用 `ls -l` / `ls -a` 逛遍 `/home /etc /var /tmp`，说出各自用途
- [ ] 建 `/tmp/d1`，用 `mkdir -p` `touch` `cp -r` `mv` `rm -r/-f` 增删一个目录
- [ ] 用 `tail -f <某日志>` 实时跟读日志输出
- [ ] 综合题：把 `/etc/hosts` 复制到 `/tmp/d1/` 改名为 `hosts.bak`

### 自测
- [ ] 能解释 `ls -la` 里的 `-rw-r--r--` 含义
- [ ] 能说清 `tail -f` 和 `tail` 的区别

### 收尾
- [ ] A 层命令凭记忆敲一遍（ls/cd/pwd/touch/cp/mv/rm/cat/tail）
- [ ] [ ] 记下当天面试话术

## D2 · 权限 + 用户/组 + 链接（A+B）

### 任务

- [ ] 用 `chmod` 把文件改成 `644`、`755`，用 `chown` 换属主
- [ ] `useradd tom`、`passwd tom`，理解 `su` / `sudo`
- [ ] 讲清软链接 vs 硬链接原理
- [ ] 实操：`ln`(硬) 与 `ln -s`(软)，删源观察异同

### 自测

- [ ] 能说清删掉源文件后，软链和硬链各自表现

### 收尾

## D3 · 进程 + 系统服务 + 日志（A，最贴部署）

### 任务
- [ ] 讲清程序(静态) 与进程(运行实例, 有 PID/PPID) 的区别
- [ ] 用 `ps -ef`、`top` 找到吃资源的进程并说出列含义
- [ ] 启 `sleep 1000` 再 `kill`；用 `nohup 命令 &` 放后台
- [ ] `systemctl status/restart/enable nginx`，说明与 kill 的区别
- [ ] 到 `/var/log/` 查日志，用 `journalctl -u nginx` 看服务日志

### 自测
- [ ] 能答出"服务挂了不重启怎么排查"
- [ ] 能说清 `kill -9` 与 `kill`(15) 的区别

### 收尾
- [ ] A 层命令凭记忆敲一遍（ps/top/kill/systemctl/journalctl）
- [ ] [ ] 记下当天面试话术
